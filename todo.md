# AuroraPet — Tarefas do projeto

## Exportação Godot para Web

- [ ] Confirmar a versão da Godot 4 usada no projeto.
- [ ] Instalar ou configurar o template de exportação Web/HTML5.
- [ ] Definir a cena principal Godot como entrada do jogo.
- [ ] Configurar viewport horizontal responsiva para celular e PC.
- [ ] Testar entrada por teclado, toque e mouse no navegador.
- [ ] Garantir que o salvamento local funcione offline no HTML5.
- [ ] Exportar o projeto para HTML5.
- [ ] Testar o build exportado em servidor local.
- [ ] Criar workflow do GitHub Actions para publicar o build no GitHub Pages.
- [ ] Adicionar instruções de publicação no README.
